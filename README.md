## Local Backup Workflow (`old/`)

To keep previous UI versions before editing screens:

- `npm run dev` now creates a screen snapshot automatically in `old/screens/<timestamp>/src/screens`.
- Back up a single file manually:

```
npm run backup:file -- src/screens/Screen4/Screen4.tsx
```

- Restore a backup file when needed:

```
npm run restore:file -- old/src/screens/Screen4/Screen4.old.20260224-130000.tsx src/screens/Screen4/Screen4.tsx
```
